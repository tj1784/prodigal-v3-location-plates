# The Prodigal Son v3: location-plate packages for Grok

21 Oct 2026. Nothing here is approved.

- Each scene folder is laid out like SC01_PLATES: README.md (the order, the tools, what to attach), prompts/, maps/, text/ and data/.
- There are no image references; the only pictures are the staging maps.
- A plate redrawn from an earlier scene's plate names that file in its first line, for example `attach the plate of sc02 01_A_plate`. So draw the scenes in film order, after Scene 1 (its own package).
